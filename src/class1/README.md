# 📘 Java Basic - 클래스와 데이터 

이번 학습에서는 **변수 / 배열 / 클래스**를 비교하면서,  
왜 자바에서 클래스를 사용하는지와 객체지향의 기초 개념을 배웠다.

---

##  이번에 학습한 핵심 내용

### 1) 변수를 여러 개 쓰는 방식의 한계
처음에는 학생 정보를 아래처럼 변수로 각각 관리했다.

- `student1Name`, `student1Age`, `student1Grade`
- `student2Name`, `student2Age`, `student2Grade`

이 방식은 데이터가 늘어날수록 변수도 계속 늘어나고,  
출력/수정 코드가 반복되어 **확장성과 유지보수성이 떨어진다**는 점을 확인했다.

---

### 2) 배열로 개선할 수 있는 점과 한계
배열을 사용하면 반복문으로 데이터를 처리할 수 있어서,  
변수만 사용할 때보다 훨씬 효율적으로 관리할 수 있다.

예)
- `String[] studentNames`
- `int[] studentAges`
- `int[] studentGrades`

하지만 한 학생의 정보가 여러 배열에 나뉘어 저장되기 때문에,  
항상 같은 인덱스를 맞춰야 하고 실수할 가능성이 크다.  
즉, **데이터를 “하나의 묶음”으로 다루기 어렵다**는 한계를 배웠다.

---

### 3) 클래스로 관련 데이터를 하나로 묶기
이 한계를 해결하기 위해 `Student` 클래스를 만들었다.

- `name`
- `age`
- `grade`

이렇게 관련 있는 데이터를 하나의 클래스에 모아서 관리하면,  
학생 1명의 정보를 **하나의 객체**로 다룰 수 있게 된다.

➡️ 이번 파트에서 가장 중요한 학습 포인트:  
**“관련된 데이터는 클래스로 묶는다.”**

---

### 4) 클래스, 객체, 인스턴스 개념 이해
클래스를 만들고 `new` 키워드로 객체를 생성하면서  
다음 개념을 구분해서 학습했다.

- **클래스(Class)**: 설계도
- **객체(Object)**: 설계도로 만든 실제 결과물
- **인스턴스(Instance)**: 특정 클래스에서 생성된 객체

즉, `Student student1 = new Student();` 에서  
`student1`은 `Student` 클래스의 인스턴스이다.

---

### 5) 참조값(주소값) 개념 이해
클래스 타입 변수에는 값 자체가 들어가는 것이 아니라,  
객체가 저장된 위치를 가리키는 **참조값**이 저장된다는 점을 배웠다.

그리고 `.`(dot) 연산자를 통해 객체 내부의 필드에 접근한다.

- `student1.name = "학생1";`
- `student1.age = 15;`

이 부분은 이후 배우게 될 **메서드 호출, 매개변수 전달, 객체 공유**와도 연결되는 중요한 개념이다.

---

### 6) 객체 배열로 확장하기
학생 객체가 여러 개 생기면, 객체도 배열로 관리할 수 있다.

- `Student[] students = {student1, student2};`

이렇게 하면 단순히 데이터를 저장하는 수준을 넘어서,  
**“객체 단위”로 반복문 처리**가 가능해진다.

---

### 7) 반복문으로 객체 데이터 출력하기
객체 배열을 `for`문 / 향상된 `for`문으로 출력하면서  
배열 + 클래스 조합이 얼마나 효율적인지 학습했다.

특히 향상된 `for`문은 인덱스 없이 객체를 바로 꺼내 사용할 수 있어  
가독성이 더 좋아진다는 점을 익혔다.

---



##  이번 파트에서 얻은 가장 중요한 이해

- 데이터가 많아질수록 “묶어서 관리”해야 한다
- 클래스는 이 묶음을 만들기 위한 사용자 정의 타입이다
- 객체는 클래스로부터 생성된 실제 데이터 단위다
- 자바는 객체를 참조값으로 다룬다
- 배열과 클래스를 함께 쓰면 코드가 훨씬 깔끔해진다

---

##  한 줄 정리

이번 학습을 통해,  
**“관련된 데이터는 클래스로 묶고, 객체 단위로 다루는 것이 자바의 기본”** 이라는 점을 이해했다.
