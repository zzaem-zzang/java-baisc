# 📘 Java Basic - 기본형과 참조형

이번 학습에서는 자바의 데이터 타입을 **기본형(Primitive Type)** 과 **참조형(Reference Type)** 으로 구분하고, 변수 대입과 메서드 호출 시 두 타입이 어떻게 다르게 동작하는지 이해했다.

---

## 이번에 학습한 핵심 내용

---

###  기본형 vs 참조형의 차이

자바의 데이터 타입은 크게 두 가지로 나뉜다.

####  기본형 (Primitive Type)

- 변수에 **실제 값**이 직접 저장된다.
- 예: `int`, `long`, `double`, `boolean`
- 산술 연산이 가능하다.
- `null`을 할당할 수 없다.

```java
int a = 10;
int b = 20;
int sum = a + b; // 가능
```

---

####  참조형 (Reference Type)

- 변수에 **객체의 주소값(참조값)** 이 저장된다.
- 예: 클래스, 배열
- 산술 연산이 불가능하다.
- `null`을 할당할 수 있다.

```java
Student s1 = new Student();
Student s2 = new Student();
// s1 + s2; // 오류 발생
```

-> 참조형은 실제 값이 아니라 주소값만 가지고 있기 때문에 직접 계산할 수 없다.

---

###
- `기본형` → 값을 직접 저장
- `참조형` → 객체의 위치(주소)를 저장

---

### 자바의 대원칙 – "항상 값을 복사해서 대입한다"

자바에서 변수에 값을 대입할 때는 항상 **변수 안에 들어있는 값을 복사해서 전달**한다.

---

####  기본형 대입

```java
int a = 10;
int b = a;
```

- b에는 10이 복사된다.
- 이후 a의 값을 바꿔도 b는 영향을 받지 않는다.

---

#### 참조형 대입

```java
Data dataA = new Data();
Data dataB = dataA;
```

- dataA 안에 있는 **참조값(주소)** 이 복사된다.
- 두 변수는 같은 객체를 가리키게 된다.

```java
dataA.value = 20;
```

이 경우에는 dataB.value도 20이 된다.

---

### 기본형과 참조형 차이

- 기본형: 실제 값이 복사된다.
- 참조형: 참조값(주소)이 복사된다.
  → 결국 하나의 객체를 여러 변수가 공유하게 된다.

---

###  메서드 호출에서의 차이

####  기본형 매개변수 전달

```java
int a = 10;
changePrimitive(a);

static void changePrimitive(int x) {
    x = 20;
}
```

메서드 내부에서 값이 변경되어도 원래 변수 a는 변하지 않는다.

이유는 값이 복사되어 전달되었기 때문이다.

---

#### 참조형 매개변수 전달

```java
Data dataA = new Data();
dataA.value = 10;
changeReference(dataA);

static void changeReference(Data dataX) {
    dataX.value = 20;
}
```

- 참조값이 복사된다.  
- 같은 객체를 가리킨다.  
- 객체 내부 값이 변경된다.

따라서 dataA.value도 20으로 변경된다.

---

###  메서드 호출 정리

- 기본형 → 값 복사 → 원본 영향 없음
- 참조형 → 참조값 복사 → 객체 내부 변경 시 원본도 변경됨

---

### 변수와 초기화

####  변수의 종류

- 멤버 변수 (필드)
- 지역 변수 (메서드 내부, 매개변수 포함)

---

####  초기화 차이

| 구분 | 초기화 방식 |
|------|------------|
| 멤버 변수 | 자동 초기화 |
| 지역 변수 | 반드시 직접 초기화 |

멤버 변수의 기본 초기값:

- 숫자 → 0
- boolean → false
- 참조형 → null

---

###  null의 의미

null은 **참조할 대상이 없다**는 의미이다.

```java
Data data = null;
```

이 상태에서

```java
data.value = 10;
```

을 실행하면?

→ **NullPointerException 발생**

---

###  NullPointerException 원리

null 상태에서 `.` (dot)을 찍으면 예외가 발생한다.

예:

```java
bigData.data.value
```

만약 bigData.data가 null이라면,

```java
null.value
```

와 동일하다.

→ 참조할 객체가 없기 때문에 예외가 발생한다.

---

### 해결 방법

```java
bigData.data = new Data();
```

참조할 객체를 생성해주면 문제를 해결할 수 있다.

---

## 이번 파트에서 얻은 가장 중요한 이해

- 자바는 항상 값을 복사해서 전달한다.
- 기본형은 실제 값이 복사된다.
- 참조형은 주소값이 복사된다.
- 참조형은 하나의 객체를 여러 변수가 공유할 수 있다.
- null 상태에서 .을 찍으면 `NullPointerException`이 발생한다.
- 멤버 변수는 자동 초기화되지만, 지역 변수는 반드시 직접 초기화해야 한다.

---

## 한 줄 정리

> 자바는 항상 값을 복사해서 전달하며, 참조형은 객체의 주소를 공유한다는 점이 기본형과의 핵심 차이이다.
